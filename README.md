\# AgriTwin AI



Explainable digital twin for sensor-driven irrigation advisory.



\- backend/: Java Spring Boot backend and web dashboard

\- ai-engine/: Python FastAPI AI engine (LSTM, explainability, chatbot)

\- hardware/: ESP32 Arduino sketch

\- database/: MySQL schema
